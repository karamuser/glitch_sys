About

حول التطبيق

Glitch Sys manages VPN, DNS, and blocks malicious domains. Works on GNU/Linux (CLI + GUI) and Android via Termux (CLI).

Glitch Sys يدير VPN و DNS ويحجب المواقع الخبيثة. يعمل على GNU/Linux (CLI + GUI) وأندرويد عبر Termux (CLI).

Android (Termux)

أندرويد (Termux)

Download Termux from GitHub:

حمّل Termux من GitHub:

Download Termux تنزيل Termux

Then run in Termux:

ثم شغّل في Termux:

pkg install python git -y
git clone https://github.com/karamuser/glitch_sys.git
cd glitch_sys/src
pip install rich
python glitch_sys.py help
On Android: Blocking and VPN require root. CLI commands work normally.
على أندرويد: الحجب و VPN يحتاجان root. أوامر CLI تعمل عادةً.

Linux Installation

التنزيل على Linux

Option 1: Binary (x86_64)

الخيار 1: ثنائي (x86_64)

wget https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_x86_64
chmod +x glitch_linux_x86_64
sudo mv glitch_linux_x86_64 /usr/local/bin/glitch
glitch help

For GUI version: glitch_linux_x86_64_gui

للنسخة الرسومية: glitch_linux_x86_64_gui

Option 2: Source Code (Any Distro)

الخيار 2: الكود المصدري (أي توزيعة)

git clone https://github.com/karamuser/glitch_sys.git
cd glitch_sys/src
pip install rich
python glitch_sys.py help

For GUI: pip install kivy && python glitch_sys.py gui

للواجهة: pip install kivy && python glitch_sys.py gui

Commands

الأوامر

glitch help                Show all commands
glitch open vpn            Show VPN list
glitch open dns            Show DNS list
glitch start vpn     Start a VPN
glitch start dns     Set DNS
glitch rm vpn        Stop a VPN
glitch rm dns              Reset DNS
glitch scan        Analyze a domain
glitch block               Block threats
glitch unblock             Unblock all
glitch status              System status
glitch update              Update threat DB
glitch gui                 Launch GUI
glitch exit                Exit
