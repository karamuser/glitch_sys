About

حول التطبيق

Glitch Sys is a command-line tool that manages VPN, DNS, and blocks malicious domains. It works on GNU/Linux distributions and Android (via Termux). Built with Python and designed for privacy and security.

Glitch Sys أداة سطر أوامر تدير VPN و DNS وتحجب المواقع الخبيثة. تعمل على توزيعات GNU/Linux وأندرويد (عبر Termux). مبنية بلغة Python ومصممة للخصوصية والأمان.

Linux Installation

التنزيل على Linux

For x86_64 (Most Desktops and Laptops)

لـ x86_64 (أغلب الحواسيب المكتبية والمحمولة)

wget https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_x86_64
chmod +x glitch_linux_x86_64
sudo mv glitch_linux_x86_64 /usr/local/bin/glitch
sudo glitch start

Download URL: https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_x86_64

رابط التنزيل: https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_x86_64

For ARM64 (Raspberry Pi, ARM Laptops)

لـ ARM64 (راسبيري باي، لابتوبات ARM)

wget https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_arm64
chmod +x glitch_linux_arm64
sudo mv glitch_linux_arm64 /usr/local/bin/glitch
sudo glitch start

Download URL: https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_arm64

رابط التنزيل: https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_arm64

Requires sudo to modify /etc/hosts. Only run on systems you own.
يحتاج sudo لتعديل ملف hosts. شغّله فقط على الأجهزة التي تملكها.

Android (Termux)

أندرويد (Termux)

Download Termux from F-Droid or GitHub, then run:

حمّل Termux من F-Droid أو GitHub، ثم شغّل:

pkg update && pkg upgrade -y
pkg install python git -y
pip install rich
git clone https://github.com/karamuser/glitch_sys.git
cd glitch_sys/src
python glitch_sys.py start

Termux F-Droid: https://f-droid.org/packages/com.termux/

Termux من F-Droid: https://f-droid.org/packages/com.termux/

Termux Latest: https://github.com/termux/termux-app/releases/latest

أحدث Termux: https://github.com/termux/termux-app/releases/latest

Android blocks /etc/hosts modification. VPN must be configured via system settings.
أندرويد يمنع تعديل hosts. VPN يجب إعداده من إعدادات النظام.

Commands Reference

مرجع الأوامر

Basic

الأوامر الأساسية

Command الأمر Description الشرح
glitch start Start system and block threats تشغيل النظام وحجب التهديدات
glitch help Show all commands عرض كل الأوامر
glitch ls commands Same as help مثل help
glitch status Show OS, architecture, and threat count عرض النظام والمعمارية وعدد التهديدات
glitch exit Unblock all and exit فك الحجب والخروج

VPN

إدارة VPN

Command الأمر Description الشرح
glitch open vpn Show available VPN list عرض قائمة VPN المتوفرة
glitch start vpn <name> Start a specific VPN (e.g. proton) تشغيل VPN محدد (مثل proton)
glitch start vpn .all Start all VPNs تشغيل كل الـ VPNs
glitch rm vpn <name> Stop a specific VPN إيقاف VPN محدد
glitch rm vpn .all Stop all VPNs إيقاف كل الـ VPNs

DNS

إدارة DNS

Command الأمر Description الشرح
glitch open dns Show available DNS list عرض قائمة DNS المتوفرة
glitch start dns <name> Set a specific DNS (cloudflare, google, quad9) تعيين DNS محدد (cloudflare, google, quad9)
glitch start dns .all Apply all DNS servers تعيين كل سيرفرات DNS
glitch rm dns Reset DNS to default إرجاع DNS للافتراضي

Security

الأمان

Command الأمر Description الشرح
glitch scan <domain> Analyze a domain for threats (0-100 score) تحليل رابط للتهديدات (درجة 0-100)
glitch block Block all threats from database حجب كل التهديدات من القاعدة
glitch unblock Remove all blocks فك كل الحجب
glitch update Download latest threat database تنزيل أحدث قاعدة تهديدات

GUI

الواجهة الرسومية

Command الأمر Description الشرح
