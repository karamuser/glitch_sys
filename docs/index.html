About

حول التطبيق

Glitch Sys is a tool that manages VPN, DNS, and blocks malicious domains. It works on GNU/Linux distributions (CLI + GUI) and Android (CLI via Termux). Built with Python and designed for privacy and security.

Glitch Sys أداة تدير VPN و DNS وتحجب المواقع الخبيثة. تعمل على توزيعات GNU/Linux (CLI + GUI) وأندرويد (CLI عبر Termux). مبنية بلغة Python ومصممة للخصوصية والأمان.

Linux Installation

التنزيل على Linux

x86_64 - CLI Version (Lightweight)

x86_64 - نسخة CLI (خفيفة)

wget https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_x86_64
chmod +x glitch_linux_x86_64
sudo mv glitch_linux_x86_64 /usr/local/bin/glitch
sudo glitch start

Direct URL: https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_x86_64

الرابط المباشر: https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_x86_64

x86_64 - GUI Version (Graphical Interface)

x86_64 - نسخة GUI (واجهة رسومية)

wget https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_x86_64_gui
chmod +x glitch_linux_x86_64_gui
./glitch_linux_x86_64_gui

Direct URL: https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_x86_64_gui

الرابط المباشر: https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_x86_64_gui

ARM64 - Source Code (Raspberry Pi, ARM Laptops)

ARM64 - الكود المصدري (راسبيري باي، لابتوبات ARM)

git clone https://github.com/karamuser/glitch_sys.git
cd glitch_sys/src
pip install rich
python glitch_sys.py start

For GUI: pip install kivy && python glitch_sys.py gui

للواجهة: pip install kivy && python glitch_sys.py gui

Requires sudo to modify /etc/hosts. Only run on systems you own.
يحتاج sudo لتعديل ملف hosts. شغّله فقط على الأجهزة التي تملكها.

Android (Termux)

أندرويد (Termux)

Download Termux from F-Droid or GitHub, then run:

حمّل Termux من F-Droid أو GitHub، ثم شغّل:

pkg update && pkg upgrade -y
pkg install python git -y
pip install rich
git clone https://github.com/karamuser/glitch_sys.git
cd glitch_sys/src
python glitch_sys.py start

Termux F-Droid: https://f-droid.org/packages/com.termux/

Termux من F-Droid: https://f-droid.org/packages/com.termux/

Termux Latest: https://github.com/termux/termux-app/releases/latest

أحدث Termux: https://github.com/termux/termux-app/releases/latest

Android blocks /etc/hosts modification. VPN must be configured via system settings. GUI is not supported on Termux (use CLI).
أندرويد يمنع تعديل hosts. VPN يجب إعداده من إعدادات النظام. الواجهة الرسومية غير مدعومة على Termux (استخدم CLI).
