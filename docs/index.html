About

حول التطبيق

Glitch Sys is a tool that manages VPN, DNS, and blocks malicious domains. It works on GNU/Linux distributions and Android (via Termux). The Linux x86_64 binary supports both CLI and GUI. Other platforms run from source code via Python.

Glitch Sys أداة تدير VPN و DNS وتحجب المواقع الخبيثة. تعمل على توزيعات GNU/Linux وأندرويد (عبر Termux). نسخة Linux x86_64 تدعم CLI و GUI. باقي الأنظمة تعمل من الكود المصدري عبر Python.

One-Line Installation

التثبيت بأمر واحد

Works on Linux and Termux (Android).

يعمل على Linux و Termux (أندرويد).

curl -sL https://raw.githubusercontent.com/karamuser/glitch_sys/main/install.sh | bash

The script detects your system and installs everything automatically.

السكربت يكتشف نظامك ويثبت كل شي تلقائياً.

Linux Installation

التنزيل على Linux

x86_64 - CLI Version (Binary)

x86_64 - نسخة CLI (ثنائية)

wget https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_x86_64
chmod +x glitch_linux_x86_64
sudo mv glitch_linux_x86_64 /usr/local/bin/glitch
sudo glitch start

x86_64 - GUI Version (Binary)

x86_64 - نسخة GUI (ثنائية)

wget https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_x86_64_gui
chmod +x glitch_linux_x86_64_gui
./glitch_linux_x86_64_gui

ARM64 - Source Code (Raspberry Pi, ARM Laptops)

ARM64 - الكود المصدري (راسبيري باي، لابتوبات ARM)

curl -sL https://raw.githubusercontent.com/karamuser/glitch_sys/main/install.sh | bash

After install: cd ~/glitch_sys/src && python glitch_sys.py start

بعد التثبيت: cd ~/glitch_sys/src && python glitch_sys.py start

Requires sudo to modify /etc/hosts. Only run on systems you own.
يحتاج sudo لتعديل ملف hosts. شغّله فقط على الأجهزة التي تملكها.

Android (Termux)

أندرويد (Termux)

Step 1: Install Termux

الخطوة 1: تثبيت Termux

Download from GitHub (latest version):

حمّل من GitHub (أحدث إصدار):

URL: https://github.com/termux/termux-app/releases/latest

الرابط: https://github.com/termux/termux-app/releases/latest

Step 2: Run Installer

الخطوة 2: تشغيل المثبت

curl -sL https://raw.githubusercontent.com/karamuser/glitch_sys/main/install.sh | bash

After install: cd ~/glitch_sys/src && python glitch_sys.py start

بعد التثبيت: cd ~/glitch_sys/src && python glitch_sys.py start

Android blocks /etc/hosts modification. VPN must be configured via system settings. GUI is not supported on Termux (use CLI).
أندرويد يمنع تعديل hosts. VPN يجب إعداده من إعدادات النظام. الواجهة الرسومية غير مدعومة على Termux (استخدم CLI).
