About

حول التطبيق

Glitch Sys manages VPN, DNS, and blocks malicious domains. Works on GNU/Linux and Android via Termux. Linux x86_64 supports CLI + GUI. Other platforms run from source.

Glitch Sys يدير VPN و DNS ويحجب المواقع الخبيثة. يعمل على GNU/Linux وأندرويد عبر Termux. Linux x86_64 يدعم CLI + GUI. باقي الأنظمة تعمل من الكود المصدري.

One-Line Installation

التثبيت بأمر واحد

Works on any Linux distro and Termux:

يعمل على أي توزيعة لينكس و Termux:

curl -sL https://raw.githubusercontent.com/karamuser/glitch_sys/main/install.sh | bash

Auto-detects system and installs dependencies.

يكتشف النظام تلقائياً ويثبت المتطلبات.

Android (Termux)

أندرويد (Termux)

Step 1: Download Termux from GitHub:

الخطوة 1: حمّل Termux من GitHub:

Download Termux تنزيل Termux

Step 2: Run in Termux:

الخطوة 2: شغّل في Termux:

pkg update && pkg upgrade -y
pkg install python git -y
git clone https://github.com/karamuser/glitch_sys.git
cd glitch_sys/src
pip install rich
python glitch_sys.py help
On Android: Blocking and VPN require root. CLI commands work normally.
على أندرويد: الحجب و VPN يحتاجان root. أوامر CLI تعمل عادةً.

Linux Installation

التنزيل على Linux

Option 1: Pre-built Binary (x86_64)

الخيار 1: ملف ثنائي جاهز (x86_64)

Download the pre-built binary (no Python needed):

حمّل الملف الثنائي الجاهز (لا يحتاج Python):

# CLI version
wget https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_x86_64
chmod +x glitch_linux_x86_64
sudo mv glitch_linux_x86_64 /usr/local/bin/glitch
glitch help

# GUI version
wget https://github.com/karamuser/glitch_sys/releases/latest/download/glitch_linux_x86_64_gui
chmod +x glitch_linux_x86_64_gui
./glitch_linux_x86_64_gui

Option 2: Source Code (Any Distro / ARM)

الخيار 2: الكود المصدري (أي توزيعة / ARM)

For ARM64, i686, or any distro:

لـ ARM64، i686، أو أي توزيعة:

git clone https://github.com/karamuser/glitch_sys.git
cd glitch_sys/src
pip install rich
python glitch_sys.py help

# For GUI (x86_64 only):
pip install kivy
python glitch_sys.py gui

All Commands

كل الأوامر

glitch help                Show all commands
glitch open vpn            Show VPN list
glitch open dns            Show DNS list
glitch start vpn     Start a VPN
glitch start vpn .all      Start all VPNs
glitch start dns     Set DNS
glitch start dns .all      Apply all DNS
glitch rm vpn        Stop a VPN
glitch rm vpn .all         Stop all VPNs
glitch rm dns              Reset DNS
glitch scan        Analyze a domain
glitch block               Block threats
glitch unblock             Unblock all
glitch status              System status
glitch update              Update threat DB
glitch gui                 Launch GUI
glitch exit                Exit

Hidden (Easter Eggs):
glitch neofetch            System info ASCII
glitch cowsay         Cow says message
glitch matrix              Matrix effect
glitch linux               Tux penguin
glitch ls                  Fake file list
